# wechat-group-expert-course

> 微信群聊记录 →「专家课」课程体提炼 Skill

把微信群聊原始记录，按「领域专家 + 老师」双重视角提炼成可阅读的课程体，再用 baoyu grace 模板美化。支持多群**逐群串行**处理。

## 适用场景

- 说「做专家课」「群聊转课程」「把群聊提炼成课」时调用。
- 生财航海群、付费社群等高质量聊天记录的沉淀与二次学习。

## 四步流程

1. **确认导出范围**：问用户要导出哪些群 + 时间范围。
2. **导出原始记录**：调 `wechat-group-batch-export` 得到 `<群名>/messages.json`。
3. **建人设提炼精华（逐群串行，一次一篇）**：

   > 你作为一名其对应的相关类型专家的头脑和老师，把其中的精华部分总结提炼出来；内容要让作为学生的我看得懂，且一定不要漏掉任何需要记忆下来的知识点。

   - 先判断群对应领域（出海 / SEO / AI 视频带货 / 热词游戏站 …），定「对应类型专家」身份。
   - 只留精华（方法 / 工作流 / 工具 / 数据 / 案例 / 踩坑 / 资源），剔除水群。
   - 不漏知识点，明确标「必记清单」。

4. **套标准模板美化（双角色闭环）**：
   - 生产：以专家人设把精华 MD 套进 baoyu grace 模板 → HTML。
   - 验收：切「普通阅读者」视角审可读性 / 好看 / 舒服，不过关就改。
   - 引擎：`baoyu-markdown-to-html` →
     `npx -y bun main.ts <md> --theme grace --color #0F4C81 --font-size 17 --font-family sans`

## 关键约束

- ⚠️ 多群必须**单群单跑**，不能同时给所有群建人设一起跑。
- 第四步是呈现 / 排版层，不再提炼内容、不跨群汇总。
